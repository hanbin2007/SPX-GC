# 江苏省常州高级中学 · Material 3 直播包装（SPX 模板包）

以 Google Material You / **Material 3 Expressive** 为设计语言、校徽藏青 `#1A3E71` 与青色 `#30B8BD` 为主色的一整套直播图文包装。
所有模板共用一套设计令牌、形状库和动效引擎，彼此之间会联动。

预览：启动 SPX 后打开 `http://localhost:5656/templates/custom/czgz-md3/demo.html`，这是一个和 SPX 渲染器行为一致的五层预览台。

## 模板一览

| 文件 | 内容 | SPX 层 (webplayout) | 输出方式 |
| --- | --- | --- | --- |
| `CZ_FULLSCREEN.html` | 全屏卡：即将开始（倒计时）/ 中场休息 / 感谢观看，深浅两套配色 | 1 | manual |
| `CZ_AGENDA.html` | 议程 / 节目单卡片，Continue 逐项推进 | 1 | manual，steps 10 |
| `CZ_NAME.html` | 人名条（左 / 右，可带标签） | 2 | manual |
| `CZ_CAPTION.html` | 标题条（栏目色块 + 主副标题） | 2 | manual |
| `CZ_TICKER.html` | 滚动字幕 | 3 | manual |
| `CZ_BUG.html` | 台标角标：标志库与 1–4 标志组（驱动所有图文的标志）+ 直播/回放/录播 + 时钟 | 4 | manual |
| `CZ_OPENER.html` | 开场片头：约 35 秒、九场（1907、校园、日夜、宝塔、校名石、校徽、标版），按背景音乐卡点，结束后自动揭开直播画面或停在校徽画面 | 5 | manual |
| `CZ_TRANSITION.html` | 转场（约 0.7 秒完全遮挡，此时切机位）。遮挡层用开场片头的背景素材：暗色校园照片、光芒、大饼干衬底、轨道环、粒子、装饰形状和放射光线，全程都在动 | 5 | none（播一次自动走完） |

层号的分配原则：会同时在画面上的元素各占一层；互斥的元素共用一层（全屏卡与议程卡、人名条与标题条）。
第 5 层最上，转场总能盖住一切。

## 设计语言

- **形状**：12 瓣“饼干”（cookie）是整套包装的主形状：校徽底座、全屏卡的揭幕窗口、倒计时圆盘、转场都用它。
  辅以 9 瓣饼干、四叶草、八角太阳、四角星等 M3 Expressive 形状作点缀。
- **连接式分段**：人名条、角标、滚动字幕都由等高的分段拼接，外侧大圆角、内侧小圆角（M3 connected button group）。
- **颜色**：藏青承载主要信息，青色用于栏目、标签和强调，红色只用于“直播”状态。
- **字体**：内置 Google Sans Flex（西文与数字，使用 ROND 圆润轴）和 Noto Sans SC（中文，按字符分片加载），离线可用，任何机器上字形一致。
- **动效**：使用 M3 Expressive 的弹簧参数（spatial fast / default / slow，effects fast / default / slow），
  入场用空间弹簧，出场用 emphasized accelerate，出场总是比入场更快。

## 过渡逻辑（transition logic）

每个模板都遵循同一套状态机：`off → in → on → out → off`。

| 操作 | 行为 |
| --- | --- |
| 播放 (play) | 分段依次弹入，文字从裁切线下方升起 |
| 更新 (update)，播出中 | 原地形变：变化的文字按“共享 Y 轴”换出换入，卡片宽度用弹簧跟随新内容，校徽底座转过一瓣（30°，轮廓不变） |
| 更新，未播出 | 直接换内容，下次播放时生效 |
| 下一步 (next) | 议程卡：高亮指示条弹到下一项，上一项变为已完成（打勾） |
| 停止 (stop) | 逆序收起，时长约为入场的 60% |
| 任意时刻打断 | 每个属性单独动画，打断时从当前画面帧继续，不会跳变。例如入场一半时收起、收起一半时再播放 |

### 同层无缝接替

SPX 每次播放都会重新载入该层的模板页面。若同一层上一条同类图文还在播出，新模板会接过它的状态：

- 人名条 ⇄ 标题条（同属 strap 家族）：从上一条的形状直接形变成下一条，不会先收起再弹出；
- 两张全屏卡之间：不再重新揭幕，只切换内容；倒计时参数不变时继续计时；
- 滚动字幕：从上一条停下的位置继续滚动；
- 人名条左右位置变化时：先收起，再从另一侧弹出。

SPX 重新载入页面时，画面仍可能空白一帧左右。播出中改内容最平滑的方式是在 SPX 里编辑字段后点“更新”。

### 图文之间的联动

模板之间通过 BroadcastChannel 通信，节目输出和 SPX 预览窗口相互隔离。

- 滚动字幕在播：人名条 / 标题条整体上移 46px 让位，收起后回落；
- 全屏卡在播：角标自动隐藏，全屏卡开始收起后约 0.26 秒角标回来；
- 转场完全遮挡的一刻广播 `{type: "cover"}`（预览台用它切换机位背景）。

## 字段说明（摘要）

- **全屏卡**：倒计时两种写法，“时长（分钟）”从播出时起算；“到某时刻”需要把时长留空，按当天该时刻计算。主标题可以手动换行，最多两行，超长时自动缩小字号。
- **滚动字幕**：每行一条。播出中更新时，屏幕上已有的字幕滚完后接新内容，不会从头开始。
- **议程卡**：每行一项，可写 `时间 | 内容`，最多 9 项；“当前项”为 0 时不高亮。
- **角标**：状态选“不显示”可只保留标志部分。

## 开场片头

`CZ_OPENER.html` 是一段约 35 秒、分九场的开场动画，**按背景音乐卡点剪辑**。校园画面是参考照片重新绘制的矢量插画；
背景里的校园照片压成了暗色调的藏青单色（`img/photo-campus-a.webp`、`img/photo-campus-b.webp`，天空已抠成透明）。
校徽是由原图转成的矢量，在片中被“画”出来。

原则：**画面里没有任何静止的元素**，**每两场之间都是大范围的连续转场**，**每次换场都落在音乐的段落切换上**。
每个元素要么在执行编排好的动作，要么在循环的待机动作里
（树摇、旗飘、云飘、镜头缓推、年份块漂浮、校徽悬浮、装饰形状旋转和浮动、照片缓慢推移、粒子上升、波浪线流动、周期性高光）。
“停在校徽画面”模式下也一直在动。

### 背景音乐与卡点

- 音乐在 `media/opener-bgm.ogg`（123 BPM，已裁掉首尾静音，约 35 秒），由模板自己播放：片头等音乐真正开始发声才起动画，全程以音乐时间为准。
- 字段“背景音乐”可选音量 100% / 70% / 40%，或“关”（静音，另行播放同一段音乐时选这个，需与播放同时开始）。
- **OBS**：浏览器源属性里勾选“通过 OBS 控制音频”，音乐才会进入直播 / 录制的混音。
- 中途点“收起”时音乐随揭开淡出；正常播完则在最后一记重音上揭开，余音自然结束。
- 换音乐：运行 `python3 tools/gen-opener-beats.py 新音乐文件`（需要 ffmpeg 和 librosa），它会裁掉首尾静音、生成 `media/opener-bgm.ogg`，并打印节拍表 `BEATS`，
  粘贴到 `gfx/opener.js`。各场的起点写成“第几拍”（`T` 里的 `b(n)`），换了音乐要按新音乐的段落重新对一下拍号。

  不在画面里的图层会自动隐藏并暂停，不占资源。

## 标志库与标志组

思路：**每个图文元素选一个标志组，每个标志归到一个或几个组**。同组的元素显示同一个标志、一起切换。

例：角标、人名条选 1 组，议程卡、标题条选 2 组，转场选 3 组。给 1 组配的标志就只出现在角标和人名条上，以此类推。

### 1. 元素选组

角标、议程卡、人名条、标题条、全屏卡（左上徽章和圆盘里的校徽）、转场，都有一个“标志组”选项：

- 1 组 / 2 组 / 3 组 / 4 组；
- 固定学校标志：不跟任何组，一直显示校徽。

### 2. 标志归组（在角标条目里）

1. 把 PNG / SVG / JPG 放进 `logos/` 文件夹，刷新 SPX 页面。
2. 角标条目里有“标志 1–6”六组字段，每个标志单独设置：

| 字段 | 说明 |
| --- | --- |
| 文件 | 从 `logos/` 里选 |
| 所属组 | 如 `1`，或 `1 3` 表示同时属于 1 组和 3 组；清空则不使用 |
| 名称 | 只在角标里显示。留空用文件名（去掉开头的“01-”等序号），填 `-` 不显示 |
| 显示方式 | 只影响角标。自动：宽高比大于 1.35 用白色横条，否则用圆形徽章；也可以强制指定 |
| 缩放 | 70%–120%，所有元素里都生效，适合给自带留白的标志放大 |
| 停留秒数 | 这个标志在轮播里停留多久，留空用该组的默认间隔 |

内置学校标志另有“学校标志所属组”和“学校标志停留秒数”两项（默认不属于任何组）。
任何一组里没有标志时，这组显示学校标志。

### 3. 每组的切换

- 1–4 组各自设置切换方式（自动轮播 / 手动）和默认间隔。
- 每组有一个“N 组下一个标志”按钮，点一下，这一组的所有元素一起切换。
- 组里只有一个标志时不轮播，就是固定显示它。

### 工作方式

- 标志库和各组的轮播都在角标模板里运行，通过总线广播每组当前的标志。
- 角标条目需要播出过一次；收起、或被全屏卡挤开后，各组照常工作。
- 后播出的元素会马上拿到所在组当前的标志。
- 切换动画：徽章转过一瓣，旧标志缩小淡出，新标志弹入；角标的名称条同时换字，宽度弹性跟随。
- 播出中修改标志库并点“更新”：各组当前的标志若仍在组里就继续显示，被删掉的话，换到组里第一个。
- 同层接替时各组从当前标志继续。
- 横版标志放进圆形徽章会比较小，建议只让角标显示横版标志。
- 预览台里可以用“添加标志…”选本地图片试看（都归 1 组，只在预览台内有效）。
- 按钮通过 SPX 的 invoke 调用模板里的 `czGroupStep(N)`。
  浏览器控制台里可能出现一条 SPX 渲染器打出的 “Error invoking … on layer 4” 警告：它在调用完函数后还会查找 OGraf 图层，可以忽略。

## 兼容性

需要 Chromium 95 及以上：OBS 28+ 浏览器源、CasparCG 2.4+、较新的 vMix。
Chromium 113 及以上（如 OBS 31）使用真正的弹簧曲线（CSS `linear()`），更早的版本自动退回近似的贝塞尔曲线。

## 目录结构

```
czgz-md3/
  CZ_*.html          模板（含 SPXGCTemplateDefinition）
  demo.html          五层预览台
  core/              设计令牌 md3.css、动效令牌 motion.css、动效引擎 md3.js
  gfx/               各模板的样式与逻辑
  img/               校徽 emblem.png、去掉文字环的裁切版 emblem-mark.png（角标与议程卡使用）、书法校名（遮罩，可任意着色）、
                     开场片头的单色校园照片 photo-campus-*.webp
  fonts/             Google Sans Flex 子集、Noto Sans SC 分片（均为 SIL OFL 1.1）
  tools/gen-motion.js  由弹簧参数生成 core/motion.css
  tools/gen-opener-scene.py  生成开场片头的校园插画 gfx/opener-scene.js
  tools/gen-opener-photos.py 生成开场片头的单色照片和背景光芒图
  tools/gen-opener-beats.py  裁剪开场片头的背景音乐并生成节拍表
  media/             开场片头的背景音乐 opener-bgm.ogg
```

修改弹簧参数时，需要同时改 `tools/gen-motion.js` 和 `core/md3.js` 里的 `SPRINGS`，然后运行
`node tools/gen-motion.js > core/motion.css`。
