# 江苏省常州高级中学 · Material 3 直播包装（SPX 模板包）

以 Google Material You / **Material 3 Expressive** 为设计语言、校徽藏青 `#1A3E71` 与青色 `#30B8BD` 为主色的一整套直播图文包装。
所有模板共用一套设计令牌、形状库和动效引擎，彼此之间会联动。

预览：启动 SPX 后打开 `http://localhost:5656/templates/custom/czgz-md3/demo.html`，这是一个和 SPX 渲染器行为一致的五层预览台。

## 模板一览

| 文件 | 内容 | SPX 层 (webplayout) | 输出方式 |
| --- | --- | --- | --- |
| `CZ_FULLSCREEN.html` | 全屏卡：即将开始（倒计时）/ 中场休息 / 感谢观看，深浅两套配色 | 1 | manual |
| `CZ_AGENDA.html` | 议程 / 节目单卡片，Continue 逐项推进 | 1 | manual，steps 10 |
| `CZ_NAME.html` | 人名条（左 / 右，可带标签） | 2 | manual |
| `CZ_CAPTION.html` | 标题条（栏目色块 + 主副标题） | 2 | manual |
| `CZ_TICKER.html` | 滚动字幕 | 3 | manual |
| `CZ_BUG.html` | 台标角标：标志轮播（校徽 + 自加标志）+ 直播/回放/录播 + 时钟 | 4 | manual |
| `CZ_TRANSITION.html` | 转场（约 0.7 秒完全遮挡，此时切机位） | 5 | none（播一次自动走完） |

层号的分配原则：会同时在画面上的元素各占一层；互斥的元素共用一层（全屏卡与议程卡、人名条与标题条）。
第 5 层最上，转场总能盖住一切。

## 设计语言

- **形状**：12 瓣“饼干”（cookie）是整套包装的主形状：校徽底座、全屏卡的揭幕窗口、倒计时圆盘、转场都用它。
  辅以 9 瓣饼干、四叶草、八角太阳、四角星等 M3 Expressive 形状作点缀。
- **连接式分段**：人名条、角标、滚动字幕都由等高的分段拼接，外侧大圆角、内侧小圆角（M3 connected button group）。
- **颜色**：藏青承载主要信息，青色用于栏目、标签和强调，红色只用于“直播”状态。
- **字体**：内置 Google Sans Flex（西文与数字，使用 ROND 圆润轴）和 Noto Sans SC（中文，按字符分片加载），离线可用，任何机器上字形一致。
- **动效**：使用 M3 Expressive 的弹簧参数（spatial fast / default / slow，effects fast / default / slow），
  入场用空间弹簧，出场用 emphasized accelerate，出场总是比入场更快。

## 过渡逻辑（transition logic）

每个模板都遵循同一套状态机：`off → in → on → out → off`。

| 操作 | 行为 |
| --- | --- |
| 播放 (play) | 分段依次弹入，文字从裁切线下方升起 |
| 更新 (update)，播出中 | 原地形变：变化的文字按“共享 Y 轴”换出换入，卡片宽度用弹簧跟随新内容，校徽底座转过一瓣（30°，轮廓不变） |
| 更新，未播出 | 直接换内容，下次播放时生效 |
| 下一步 (next) | 议程卡：高亮指示条弹到下一项，上一项变为已完成（打勾） |
| 停止 (stop) | 逆序收起，时长约为入场的 60% |
| 任意时刻打断 | 每个属性单独动画，打断时从当前画面帧继续，不会跳变。例如入场一半时收起、收起一半时再播放 |

### 同层无缝接替

SPX 每次播放都会重新载入该层的模板页面。若同一层上一条同类图文还在播出，新模板会接过它的状态：

- 人名条 ⇄ 标题条（同属 strap 家族）：从上一条的形状直接形变成下一条，不会先收起再弹出；
- 两张全屏卡之间：不再重新揭幕，只切换内容；倒计时参数不变时继续计时；
- 滚动字幕：从上一条停下的位置继续滚动；
- 人名条左右位置变化时：先收起，再从另一侧弹出。

SPX 重新载入页面时，画面仍可能空白一帧左右。播出中改内容最平滑的方式是在 SPX 里编辑字段后点“更新”。

### 图文之间的联动

模板之间通过 BroadcastChannel 通信，节目输出和 SPX 预览窗口相互隔离。

- 滚动字幕在播：人名条 / 标题条整体上移 46px 让位，收起后回落；
- 全屏卡在播：角标自动隐藏，全屏卡开始收起后约 0.26 秒角标回来；
- 转场完全遮挡的一刻广播 `{type: "cover"}`（预览台用它切换机位背景）。

## 字段说明（摘要）

- **全屏卡**：倒计时两种写法，“时长（分钟）”从播出时起算；“到某时刻”需要把时长留空，按当天该时刻计算。主标题可以手动换行，最多两行，超长时自动缩小字号。
- **滚动字幕**：每行一条。播出中更新时，屏幕上已有的字幕滚完后接新内容，不会从头开始。
- **议程卡**：每行一项，可写 `时间 | 内容`，最多 9 项；“当前项”为 0 时不高亮。
- **角标**：状态选“不显示”可只保留标志部分。

## 角标标志轮播

1. **添加标志**：把 PNG / SVG / JPG 放进 `logos/` 文件夹，刷新 SPX 页面。
   角标条目的“标志 1–6”下拉框里就能选到这些文件。文件名就是显示名称，例如 `02-校团委.png` 显示为“校团委”，开头序号只用来排序。
2. **组成轮播**：“包含学校标志”控制内置的校徽 + 书法校名是否参与轮播，再加上最多 6 个自选标志。
3. **切换**：
   - “自动轮播”按“轮播间隔”（默认 8 秒，最少 3 秒）循环；
   - “手动”时只在点条目里的“下一个标志”按钮时切换（自动模式下点按钮也会立即切换，并重新计时）。
4. **展示方式**：
   - 接近方形的标志放进圆形徽章，旁边的藏青条显示名称（“显示名称”可关）；
   - 宽高比大于 1.35 的横版标志单独放在白色横条里，徽章让位。
5. **过渡**：
   - 徽章转过一瓣，旧标志缩小淡出、新标志弹入；
   - 名称条按共享 Y 轴换字，宽度用弹簧跟随；
   - 横版与方形之间切换时，徽章弹出或收起。

播出中修改标志列表并点“更新”：当前标志若仍在列表中就继续显示，只是轮播顺序更新。
被全屏卡挤开或收起时轮播暂停，回来后继续。同层接替时从同一个标志继续。

预览台里可以用“添加标志…”选本地图片试看（只在预览台内有效，不会写入 `logos/`）。

按钮通过 SPX 的 invoke 调用模板里的 `czLogoStep(1)`。浏览器控制台里可能出现一条 SPX 渲染器打出的 “Error invoking … on layer 4” 警告：它在调用完函数后还会查找 OGraf 图层，可以忽略。

## 兼容性

需要 Chromium 95 及以上：OBS 28+ 浏览器源、CasparCG 2.4+、较新的 vMix。
Chromium 113 及以上（如 OBS 31）使用真正的弹簧曲线（CSS `linear()`），更早的版本自动退回近似的贝塞尔曲线。

## 目录结构

```
czgz-md3/
  CZ_*.html          模板（含 SPXGCTemplateDefinition）
  demo.html          五层预览台
  core/              设计令牌 md3.css、动效令牌 motion.css、动效引擎 md3.js
  gfx/               各模板的样式与逻辑
  img/               校徽、书法校名（遮罩，可任意着色）
  fonts/             Google Sans Flex 子集、Noto Sans SC 分片（均为 SIL OFL 1.1）
  tools/gen-motion.js  由弹簧参数生成 core/motion.css
```

修改弹簧参数时，需要同时改 `tools/gen-motion.js` 和 `core/md3.js` 里的 `SPRINGS`，然后运行
`node tools/gen-motion.js > core/motion.css`。
