# 角标标志文件夹

把要用的标志放进这个文件夹，然后在 SPX 里刷新页面，
角标条目的“标志 1–6”里就能选到它们。每个标志可以单独设置所属标志组（1–4，可多选）、名称、显示方式、缩放和停留秒数；
各图文元素选择跟随哪个标志组。

- 支持 PNG、SVG、JPG（建议透明底 PNG 或 SVG，短边不少于 200 像素）。
- 默认名称取自文件名：例如 `02-校团委.png` 显示为“校团委”，开头的序号只用来排序。也可以在角标条目里给每个标志另填名称。
- 接近方形的标志放在圆形徽章里，旁边显示名称；宽度明显大于高度（宽高比大于 1.35）的标志
  会单独放在白色横条里，不再显示名称。
- 学校标志（校徽 + 书法校名）是内置的，不需要放在这里，用“包含学校标志”开关控制。
